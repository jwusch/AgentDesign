WORKFLOW REQUIREMENTS:
======================

ComfyUI workflows for SVI need the following nodes:
- WanModelLoader (from ComfyUI-WanVideoWrapper)
- LoraLoader (standard ComfyUI)
- KSamplerAdvanced (standard ComfyUI)
- VideoLoopController (from ComfyUI-WanVideoWrapper)
- ErrorRecyclingNode (from ComfyUI-WanVideoWrapper or SVI custom nodes)

CREATING YOUR OWN WORKFLOWS:
============================

You can create custom SVI workflows in ComfyUI by:

1. Load the WAN 2.1 model using WanModelLoader
2. Add LoraLoader node and select SVI LoRA
3. Set up KSampler with proper settings:
   - Padding mode: constant
   - Padding value: 0.0
4. Configure loop structure for multiple clips
5. Add error recycling mechanism
6. Set up concatenation for final video

See README-SVI.md for detailed node configuration instructions.

TESTING WORKFLOWS:
==================

Once you have workflow JSON files:
1. Place them in this directory (workflows/svi/)
2. Start ComfyUI
3. Load workflow via "Load" button
4. Verify all nodes are recognized
5. Configure inputs and parameters
6. Test with short generation first
